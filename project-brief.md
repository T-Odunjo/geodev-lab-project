# GIS-Based Waste Disposal Site Suitability and Accessibility Analysis in New Bussa

## The Question

Which locations in New Bussa, Niger State, are suitable for permanent and temporary waste disposal facilities, and how can the existing road network support access to and connectivity between these locations?

## Objectives

1. To map waste-related, environmental, physical, and human features relevant to waste disposal planning in New Bussa.

2. To identify potentially suitable locations for permanent waste disposal facilities using environmental and spatial suitability criteria.

3. To identify suitable locations for temporary waste collection or disposal facilities based on population distribution, accessibility, land availability, and environmental considerations.

4. To analyse the road network and accessibility of the proposed permanent and temporary waste disposal locations.

## Expected Outcomes

* Base map of New Bussa.
* Maps showing relevant environmental, physical and human features.
* Map of existing waste disposal and collection locations.
* Permanent waste disposal site suitability map.
* Temporary waste collection/disposal site suitability map.
* Road accessibility and connectivity map.
* Proposed waste management site network map.
* Field validation results.
* Final GIS database and project documentation.
* Recommendations for improved waste disposal planning and accessibility in New Bussa.
